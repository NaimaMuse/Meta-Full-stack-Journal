# Programming in Python

## Course Overview

This course introduces the fundamentals of Python programming and provides the foundation needed to begin developing applications with Python. It covers Python syntax, data structures, functions, programming paradigms, object-oriented programming, modules, libraries, and automated testing.

## Prerequisites

No previous programming or development experience is required. The course is designed for beginners who are willing to learn Python and start coding.

## Course Modules

### Module 1 — Getting Started with Python

* Introduction to programming and Python
* Setting up the Python development environment
* Running Python programs
* Variables and data types
* Comments and Python syntax
* User input and output
* Mathematical and logical operators
* Conditional statements
* Loops and sequences

### Module 2 — Basic Programming with Python

* Functions and parameters
* Return values
* Scope
* Python data structures
* Lists, tuples, sets, and dictionaries
* `kwargs`
* Errors and exceptions
* Exception handling
* File handling
* Creating and writing files

### Module 3 — Programming Paradigms

* Procedural programming
* Algorithms and problem solving
* Algorithmic complexity
* Big-O notation
* Functional programming
* Pure functions and recursion
* `map()` and `filter()`
* Object-Oriented Programming (OOP)
* Classes and instances
* Methods and attributes
* Abstraction
* Inheritance
* Parent and child classes
* Method resolution

### Module 4 — Modules, Packages, Libraries, and Tools

* Python modules and packages
* Python libraries
* Libraries for data analysis and data science
* Python applications in machine learning and AI
* Software testing and Quality Assurance
* Automated testing
* PyTest
* Test-Driven Development (TDD)

### Module 5 — Graded Assessment

The final module focuses on the end-of-course graded assessment. It evaluates the knowledge and practical Python programming skills developed throughout the course.

## Learning Outcomes

By completing this course, I will be able to:

* Write basic Python programs.
* Use variables, data types, operators, conditions, and loops.
* Create and use functions.
* Work with Python data structures.
* Handle errors and exceptions.
* Read from and write to files.
* Understand procedural, functional, and object-oriented programming.
* Apply basic algorithms and understand Big-O notation.
* Create classes and use inheritance and abstraction.
* Work with Python modules, packages, and libraries.
* Write automated tests using PyTest.
* Understand the fundamentals of Test-Driven Development.
